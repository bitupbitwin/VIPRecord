# 订阅星轨 · SubOrbit —— 安装说明书

> 本文面向第一次构建本软件的你，手把手从 0 到能在**手机和电脑**上跑起来。
> 不需要编程基础，照着命令复制粘贴即可。

---

## 一、先准备开发环境（只需一次）

### 1. 安装 Flutter SDK
- 打开官网：<https://docs.flutter.dev/get-started/install>
- 按你的电脑系统（Windows / macOS / Linux）下载并解压 Flutter。
- 把 Flutter 的 `bin` 目录加入系统 PATH 环境变量。
- 打开终端（命令行），执行下面命令检查是否安装成功：

```bash
flutter --version
flutter doctor
```

`flutter doctor` 会逐项检查环境，按它的提示把红叉项补齐即可（见下方各平台要求）。

### 2. 按你要发布的平台补齐工具
| 目标 | 需要安装 |
|---|---|
| 安卓手机 App | Android Studio（含 Android SDK、模拟器或用数据线连真机）|
| 苹果手机 App | 一台 Mac + Xcode + 苹果开发者账号 |
| Windows 电脑软件 | Visual Studio（勾选「使用 C++ 的桌面开发」）|
| macOS 电脑软件 | Xcode |
| Linux 电脑软件 | `clang cmake ninja-build pkg-config libgtk-3-dev` 等 |
| 网页版（最省事）| 仅需 Chrome 浏览器 |

> 只想先快速看效果？**用网页版或自己手机**即可，无需配齐所有平台。

## 二、获取代码

```bash
git clone <本仓库地址>
cd VIPRecord/app
```

> 如果你已经在本仓库目录中，直接 `cd app` 即可。

## 三、生成各平台工程并安装依赖

本仓库为保持整洁，只提交了源码（`lib/`、`pubspec.yaml`、`test/`），
各平台的工程目录需要本地生成一次：

```bash
flutter create .      # 生成 android/ ios/ windows/ macos/ linux/ web，已有 lib 与 pubspec 不会被覆盖
flutter pub get       # 下载依赖
flutter test          # （可选）运行统计算法测试，全部通过说明核心逻辑正常
```

---

## 四、运行起来

### 在手机上运行
1. 安卓：手机开启「开发者模式 + USB 调试」，用数据线连电脑；或启动一个模拟器。
2. 苹果：用 Mac + Xcode 连接 iPhone。
3. 执行：

```bash
flutter devices      # 查看已连接的设备
flutter run          # 选择对应设备运行
```

### 在电脑上运行
```bash
flutter run -d windows    # Windows 桌面
flutter run -d macos      # macOS 桌面
flutter run -d linux      # Linux 桌面
flutter run -d chrome     # 网页版（电脑浏览器）
```

## 五、打包成可安装的成品

```bash
flutter build apk         # 安卓安装包：build/app/outputs/flutter-apk/app-release.apk
flutter build ipa         # 苹果（需 Mac + 开发者账号）
flutter build windows     # Windows：build/windows/x64/runner/Release/ 下的可执行文件
flutter build macos       # macOS 应用
flutter build linux       # Linux 应用
flutter build web         # 网页版：build/web/，部署到任意静态服务器即可
```

- **安卓**：把 `app-release.apk` 传到手机点击安装即可。
- **Windows**：把 `Release` 目录整体拷贝到电脑，双击 exe 运行；也可用打包工具做成安装包。
- **网页版**：把 `build/web/` 上传到任意网页托管，电脑浏览器打开后可「安装到桌面」当本地应用用。

## 六、（可选）开启云同步：手机电脑数据互通

1. 打开 <https://supabase.com>，注册并新建一个 Project。
2. 在项目设置里找到 **Project URL** 和 **anon public key**，复制备用。
3. 打开 Supabase 的 **SQL Editor**，粘贴并运行下面三段建表语句：

```sql
create table categories (
  id text primary key, name text, emoji text,
  "colorValue" int8, "sortOrder" int8,
  "updatedAt" timestamptz, deleted bool
);
create table platforms (
  id text primary key, "categoryId" text, name text, emoji text,
  notes text, "updatedAt" timestamptz, deleted bool
);
create table subscriptions (
  id text primary key, "platformId" text, cycle text,
  amount float8, currency text,
  "startDate" timestamptz, "endDate" timestamptz,
  "autoRenew" bool, notes text, "updatedAt" timestamptz, deleted bool
);
```

4. 回到 App：**设置 → 云同步**，把 URL 和 key 填进去，打开「启用云同步」开关，保存后**重启 App** 生效。
5. 在另一台设备（手机/电脑）上填同样的 URL 和 key，数据即可互通。

## 六之二、用 IDE 打开项目（Android Studio / VS Code）

> 关键：**要打开的是 `app` 子文件夹，不是仓库根目录 `VIPRecord`。**
> Flutter 插件靠"打开目录下有没有 `pubspec.yaml"`来识别项目；`pubspec.yaml` 在 `app/` 里，
> 打开根目录会报 **"Dart SDK is not configured"**（其实 SDK 没问题，只是没认出是 Flutter 项目）。

- **Android Studio**：`File → Open…` → 选 `…\VIPRecord\app` → 打开。它认到 `pubspec.yaml`
  会自动配好 Dart/Flutter SDK，红色提示消失。右上角设备下拉选好后点 ▶ 运行。
- **VS Code**：`文件 → 打开文件夹` → 选 `…\VIPRecord\app`（需装 Flutter 扩展）→ `F5` 运行。

## 六之三、网页端（Chrome/Edge）运行需补一行脚本

云同步用的 `supabase_flutter` 在**网页端**会要求一个 Passkeys 的 `bundle.js`，否则启动报：
`Error: Passkeys Web SDK not loaded...`。**安卓和 Windows 桌面不受影响、无需此步**。

如需在浏览器预览，打开 `app\web\index.html`，在 `<head>…</head>` 之间加一行后重跑 `flutter run -d chrome`：

```html
<script src="https://github.com/corbado/flutter-passkeys/releases/download/2.4.0/bundle.js" defer></script>
```

> `web/` 是 `flutter create .` 生成的、且在 `.gitignore` 中，故此改动只需在本机做一次。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| `flutter: command not found` | Flutter 的 `bin` 没加进 PATH，重新配置环境变量 |
| IDE 报 `Dart SDK is not configured` | 你打开的是仓库根目录，改成打开 `app` 子文件夹（见六之二）|
| 网页端报 `Passkeys Web SDK not loaded` | 给 `web/index.html` 补一行 bundle.js 脚本（见六之三）；或直接用安卓/Windows |
| `flutter doctor` 有红叉 | 按它的提示安装缺失项（多为 Android SDK / Xcode / Visual Studio）|
| 运行报缺少 android/ 目录 | 没执行 `flutter create .`，补跑一次 |
| 拉取依赖很慢 | 配置 Flutter 国内镜像（`PUB_HOSTED_URL`、`FLUTTER_STORAGE_BASE_URL`）|
| 收不到到期提醒 | 在系统设置里允许本应用发送通知；iOS/安卓首次运行需授权 |
| 云同步没生效 | 确认 URL/key 正确、已建表、已开开关并**重启**了 App |
